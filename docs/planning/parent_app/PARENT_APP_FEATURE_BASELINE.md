# Felege Kidusan SSMS — Parent Mobile App Features List

**Purpose:** A dedicated, parent-focused mobile experience that connects families with their children's spiritual education, attendance, learning progress, and Sunday School community.

The app should make parents feel informed, involved, and confident that their children are receiving meaningful spiritual education, while keeping daily use simple for parents with different levels of technology experience.

## 1. Parent account and access management

- In-person parent account activation through the Sunday School registration office.
- Secure, one-time activation code issued by authorized staff.
- Parent account creation using a school-issued parent ID and password.
- Trusted-device registration during initial activation.
- Biometric or device-PIN authentication on supported devices.
- Simple daily access without repeatedly entering a password.
- Secure login on a new or unrecognized device using account credentials and fresh in-person verification.
- Forgotten-password recovery through in-person identity verification.
- View and manage trusted devices.
- Revoke access to lost or replaced devices.
- Secure logout and session expiration.
- Parent account suspension and reactivation by authorized staff.
- Support for multiple children linked to one parent account.
- Support for multiple authorized guardians per child, subject to school approval.
- Request correction of incorrect parent-child relationships.
- Amharic and English language selection.
- Clear activation and login instructions for first-time smartphone users.
- Privacy notice and parent consent during registration.

## 2. Parent home dashboard

- Personalized welcome message.
- Child profile cards.
- Switch between multiple children.
- Student photograph, name, class, and student ID where appropriate.
- Current class and Sunday School group.
- Attendance summary for the current month.
- Latest lesson update.
- Recent announcements and messages.
- Monthly report availability.
- Upcoming Sunday School events and holidays.
- Pending parent feedback requests.
- Important notices from teachers and administrators.
- Quick access to lessons, attendance, reports, messages, and profile.
- Clear indicators for unread messages and new reports.
- Friendly empty states when information is not yet available.
- Last-updated indicators so parents can distinguish current information from older records.

## 3. "What Did My Child Learn Today?" — Daily lesson updates

This is one of the app's core features.

- Receive a personalized daily lesson message.
- View lesson date, subject, topic, and class.
- Read a short explanation of the lesson taught.
- View optional classwork, exercises, or assessment notes.
- See whether the lesson was confirmed by the teacher or remains unconfirmed.
- Receive updates based on the actual lesson delivered, not only the planned curriculum.
- View previous lesson messages in chronological order.
- Browse lessons by month, subject, or class.
- Receive notifications when a new lesson update is published.
- Save important lesson updates for later.
- Share a lesson summary with another authorized guardian, where permitted.
- View teacher-approved educational resources associated with the lesson.
- View approved Bible stories, prayers, spiritual lessons, or learning materials when available.
- Receive age-appropriate suggestions for discussing the lesson at home.
- View optional questions that parents can ask their children to reinforce learning.
- Receive corrected lesson updates when a published message contains an error.

**Personalized message experience**

- Automatic insertion of the child's name.
- Appropriate Amharic grammatical forms and gender-aware language where relevant.
- Correct date, subject, lesson topic, and class information.
- Optional classwork or assessment sentence.
- Optional teacher-written personal message.
- Special encouragement messages for individual students.
- Preview of the final personalized message before publication by authorized staff.

## 18. Recommended release priorities

**Phase 1 — Essential first release**
Parent activation and login, child linking, home dashboard, daily lessons, attendance, monthly reports, notifications, and parent feedback.

**Phase 2 — Communication and engagement**
Private teacher–parent messaging, special-attention workflows, holiday greetings, event announcements, and learning-at-home resources.

**Phase 3 — Advanced experience**
Voice summaries, richer progress visualization, advanced family engagement, and additional educational resources.

## 19. The most important product decisions

1. Make the app useful every Sunday. Daily lesson updates and attendance should give parents a reason to return regularly.
2. Automate reports wherever possible. Use the approved curriculum and existing attendance records, with teachers confirming actual lessons rather than writing long reports.
3. Never invent a child's progress. Clearly distinguish planned lessons, confirmed lessons, attendance, and individually assessed learning.
4. Make parent onboarding manageable. Begin with interested parents attending an in-person registration session, then expand gradually.
5. Keep sensitive information private. Parent feedback and individual concerns must not be shared with other parents.
6. Reuse the existing SSMS system. Keep student records, attendance, classes, and permissions consistent instead of creating a separate source of truth.
7. Design for ordinary phones and unreliable internet. The app should remain straightforward, lightweight, and usable for parents with different levels of technical experience.

The overall goal is a parent app that builds a lasting connection between families and Felege Kidusan Sunday School—not simply another place to receive school notifications.
