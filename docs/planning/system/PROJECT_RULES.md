## Rule 1 — Universal AI Software Change, Patch & Update Protocol (ALWAYS APPLY)

For ANY modification, patch, update, or new feature in this project (SSMS), the
Universal AI Software Change, Patch & Update Protocol v1.0 (file:
`/home/user/uploads/UNIVERSAL AI SOFTWARE CHANGE, PATCH   UPDATE PROTOCOL.md`)
MUST be followed in full. Key non-negotiables:

1. Never modify before understanding impact (current behavior, files, functions, APIs, DB, deps, side effects, security, compatibility, regression).
2. Source of truth = actual codebase (not docs/names).
3. Classify conclusions as VERIFIED / HIGH-CONFIDENCE INFERENCE / INFERENCE / UNKNOWN.
4. Trace full execution path before editing.
5. Minimum change principle; preserve existing behavior unless requested.
6. Impact analysis + implementation plan before coding.
7. Post-implementation verification + regression + security review.
8. Final report with files changed, logic, DB, API, security, UI, testing, risks, assumptions, status.

No implementation may begin without: requirement understood, current behavior understood, relevant source inspected, dependencies traced, impact assessed, implementation plan established.
